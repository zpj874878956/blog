# 安装rancher

**注意需要能访问docker hub镜像仓库**

如果没有访问外网的环境，需要配置镜像仓库代理或者网路代理

### 1.执行docker部署

```bash
mkdir -p /data/rancher2.5.7
docker run -d --privileged -p 80:80 -p 443:443 -v /data/rancher2.5.7:/var/lib/rancher --restart=always --name rancher2.5.7 rancher/rancher:v2.5.7
注意：
必须使用 Rancher 2.5.7：建议使用当年的兼容环境：
Ubuntu 20.04 / CentOS 7
Docker 19.03.x
cgroup v1
```
