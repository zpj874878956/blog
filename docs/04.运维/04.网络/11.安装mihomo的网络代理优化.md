主要修改了两处：

1. mihomo 配置
   文件：`/data/mihomo/clash-config/config.yaml`

- Docker Hub 域名固定走香港节点：

```yaml
- DOMAIN,auth.docker.io,🇭🇰 香港节点
- DOMAIN,registry-1.docker.io,🇭🇰 香港节点
- DOMAIN,production.cloudflare.docker.com,🇭🇰 香港节点
- DOMAIN,production.cloudfront.docker.com,🇭🇰 香港节点
- DOMAIN-SUFFIX,docker.io,🇭🇰 香港节点
- DOMAIN-SUFFIX,docker.com,🇭🇰 香港节点

```

- DNS 改为通过香港节点访问 Cloudflare DoH：

```yaml
nameserver:
  - https://1.1.1.1/dns-query#🇭🇰 香港节点

```

原来的国内 DNS 把 `auth.docker.io` 解析到了错误地址，这是主要问题之一。

1. Docker 下载参数
   新建了 `/etc/docker/daemon.json`：

```json
{
  "max-concurrent-downloads": 1,
  "max-download-attempts": 5
}

```

这样避免多个镜像层同时下载把代理线路压垮，并增加失败重试次数。
