# 设置默认 Locale

执行：

```bash
update-locale LANG=zh_CN.UTF-8
```

或者：

```bash
echo 'LANG=zh_CN.UTF-8' > /etc/default/locale
echo 'LC_ALL=zh_CN.UTF-8' >> /etc/default/locale
```

然后重新登录：

```bash
source /etc/default/locale
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8
```

再检查：

```
locale
```

应该变成：

```bash
LANG=zh_CN.UTF-8
```
