AWS EC2 扩容磁盘一般分两步：**先扩 EBS 卷容量，再在 Linux 里扩分区/文件系统**。多数现代 EBS 卷可以在线扩容，不需要停机或卸载磁盘。

### 1. AWS 控制台扩容 EBS

进入：

**EC2 → Elastic Block Store → Volumes（卷）**

找到实例对应磁盘，例如当前：

```bash
50 GiB
```

选择：

```bash
Actions
→ Modify volume
→ Size
```

例如改成：

```bash
100 GiB
```

然后：

```bash
Modify
→ 确认
```

AWS 建议重要生产盘扩容前先做一次 Snapshot。卷进入 `optimizing` 状态后，就可以继续在系统里扩文件系统，不必等到完全 `completed`。[AWS 文档](https://docs.aws.amazon.com/ebs/latest/userguide/recognize-expanded-volume-linux.html?utm_source=chatgpt.com)

### 2. 登录服务器检查磁盘

先执行：

```bash
lsblk
df -hT
```

AWS Nitro 实例通常类似：

```bash
NAME        SIZE FSTYPE MOUNTPOINT
nvme0n1     100G
└─nvme0n1p1  50G xfs    /
```

这说明：

```bash
EBS磁盘：100G
分区：    50G
```

所以还需要扩分区。

执行：

```bash
growpart /dev/nvme0n1 1
```

注意这里是：

```bash
/dev/nvme0n1 1
```

中间必须有空格。AWS 官方对 `nvme0n1p1` 也是这个写法。

如果系统提示：

```bash
growpart: command not found
```

CentOS 7 安装：

```bash
yum install -y cloud-utils-growpart
```

### 3.扩文件系统

先确认：

```bash
df -hT
```

如果是你 CentOS 7.9 比较常见的 **XFS**：

```bash
/dev/nvme0n1p1  xfs
```

根目录 `/` 执行：

```bash
xfs_growfs /
```

如果是 `/data`：

```bash
xfs_growfs /data
```

XFS 要指定**挂载点**，不是块设备

如果是 **ext4**：

```bash
resize2fs /dev/nvme0n1p1
```

AWS 官方也是分别使用 `xfs_growfs` 和 `resize2fs`。

最后确认：

```bash
df -hT
lsblk
```

例如应该看到：

```bash
Filesystem           Type  Size  Used Avail Use% Mounted on
/dev/nvme0n1p1       xfs   100G   30G   70G  30% /
```

### 如果是数据盘

例如：

```bash
nvme1n1      200G
└─nvme1n1p1  100G xfs /data
```

直接：

```bash
growpart /dev/nvme1n1 1
xfs_growfs /data

lsblk
df -hT
```
